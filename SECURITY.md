# Security

Your Open Cloud API key never leaves your machine except in requests to `apis.roblox.com`. It is stored in `~/.config/roblox-monetize/api-key` with owner-only permissions, or read from `ROBLOX_API_KEY`.

Give the key only the scopes it needs: game-passes and developer-products, read and write, for the experiences you use it on.

To report a vulnerability, use GitHub's private **Report a vulnerability** button on the Security tab. Please do not open a public issue.
